Human Confidence demo

This page shows how likely it is that a person is looking at it. The server reads HumanConfidenceSource and HumanConfidence for the request alone first. Then your browser runs the 51Degrees browser tests and gets a sealed result, which it sends back to the server. The server reads the two Properties again, and its Pipeline redeems the sealed result. The License Key stays on the server.
